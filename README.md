# SoulMind 🌱

## Descrição do Projeto

O **SoulMind** é o chatbot de uma solução desenvolvida para a **SoulUp**, com o objetivo de aumentar o engajamento das pessoas com a sustentabilidade através da gamificação.

A proposta é tornar pequenas ações ambientais mais acessíveis, motivadoras e recompensadoras. Para isso, o SoulMind permite que o usuário realize missões sustentáveis, acumule pontos, acompanhe seu progresso e personalize seu avatar.

O projeto foi desenvolvido durante a **Sprint 3 de Front-end da FIAP**, dando continuidade ao projeto desenvolvido nas Sprints anteriores.

## Como Executar Localmente

Para executar o projeto localmente, é necessário ter o **Node.js** instalado.

### 1. Clone o repositório

```bash
git clone https://github.com/SoulMind-FIAP/Sprint3-SoulMind.git
```

### 2. Acesse a pasta do projeto

```bash
cd SoulMind
```

### 3. Instale as dependências

```bash
npm install
```

### 4. Execute o projeto

```bash
npm run dev
```

### 5. Acesse a aplicação

Após executar o comando, o Vite disponibilizará o endereço local no terminal.

Normalmente, a aplicação estará disponível em:

```text
http://localhost:5173
```
